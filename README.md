AML Transaction Checker
A comprehensive web-based Anti-Money Laundering (AML) compliance tool for screening financial transactions against global risk frameworks.
🌟 Features
195-Country Risk Database - Complete global coverage with risk classifications
Compliance Framework Integration - PMLA 2002, FATF, RBI, and FIU-IND standards
AI-Powered Risk Assessment - Intelligent compliance recommendations via Anthropic API
Batch Processing - Upload and screen multiple transactions via Excel files
Multi-Database Export - Download results in Excel, CSV, and JSON formats
Real-time Analysis - Instant risk scoring and flagging
🚀 Live Demo
Launch AML Checker
🛠️ Technology Stack
Frontend: React / HTML5 / CSS3
Data Processing: XLSX.js for Excel handling, PDF.js for document parsing
AI Integration: Anthropic Claude API for compliance recommendations
Styling: Custom CSS with modern dark theme
Deployment: Netlify
📋 How It Works
Input Transaction Details - Enter sender/receiver info, amount, country
Risk Assessment - System checks against 195-country risk database
Compliance Check - Cross-references with PMLA, FATF, RBI guidelines
AI Recommendations - Get intelligent next-step suggestions
Export & Report - Download comprehensive reports in multiple formats
🔒 Compliance Coverage
PMLA 2002 - Prevention of Money Laundering Act (India)
FATF Standards - Financial Action Task Force guidelines
RBI Guidelines - Reserve Bank of India AML/CFT frameworks
FIU-IND - Financial Intelligence Unit protocols
📊 Supported Features
✅ Individual transaction screening
✅ Batch file processing (Excel upload)
✅ Country risk classification (High/Medium/Low)
✅ Transaction pattern analysis
✅ Export to Excel/CSV/JSON
✅ AI-powered compliance guidance
🎓 Use Cases
Financial institutions conducting AML checks
Compliance officers screening cross-border transactions
Students learning AML frameworks (educational purposes)
Research and analysis of global money laundering risks
